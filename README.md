# Sustaining Life: Forests and Wildlife Resources

EVS presentation as a website. Everything (slides, pictures, fonts, animations) is inside `index.html`, so nothing else is needed.

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub (for example `sustaining-life`).
2. Click **Add file → Upload files** and drop in `index.html`, `.nojekyll` and this `README.md`, then **Commit changes**.
   (`.nojekyll` is hidden on Mac: in Finder press **Cmd + Shift + .** to show it. It is optional.)
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Presenting

- Next slide: **Enter**, **Space**, **→** or a presentation clicker. Previous: **←** or **Backspace**.
- **F**: fullscreen. **N**: speaker notes.
- Quiz slides: click the option a student says (or press **A–D**). Wrong answers turn red; the right one turns green and opens the answer slide.
- Add `#s12` to the end of the address to open a specific slide (here slide 12).
